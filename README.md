# PruebaGitFlow

## Descripción
Proyecto de práctica para aprender el flujo de trabajo Git Flow.

## Instalación
1. Clona el repositorio
2. Ejecuta `npm install`

## Uso
Ejecuta `npm start` para iniciar el proyecto.

## Autores
- Juan Camilo (juanacuna07)

## Flujo de trabajo Git
Se usa Git Flow con ramas: main, develop, feature, release y hotfix.

## Evidencias
- PR feature/readme-base → develop
- Tag v1.0.0
